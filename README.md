# Haris Ansari — Portfolio

Personal portfolio site for a DevOps Engineer specializing in Kubernetes, Infrastructure as Code,
CI/CD automation, and MLOps/GenAI productionization.

Built with React (Create React App).

## Sections

- **Hero** — role summary and key stats
- **Skills** — cloud, containers, IaC, CI/CD, security/observability, MLOps toolchain
- **Experience** — role timeline
- **Projects** — highlighted infrastructure and automation work
- **Certifications** — cloud certifications
- **Contact** — message form (EmailJS) and social links

## Available Scripts

In the project directory, you can run:

### `npm start`

Runs the app in development mode at [http://localhost:3000](http://localhost:3000).

### `npm run build`

Builds the app for production to the `build` folder.

### `npm test`

Runs the test suite.
